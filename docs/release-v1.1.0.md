# Z7X ADB 开启器 v1.1.0

本版为投影仪遥控器适配：

- 上下左右方向键可在两个操作按钮之间切换焦点。
- 获得焦点的按钮显示白色边框，并放大至 104.5%；离开焦点后恢复。
- 遥控器 OK（DPAD_CENTER）触发按钮点击：重新检查 ADB，或切换开机恢复状态。
- 检查过程中保留焦点，忽略重复执行请求。
- 保留启动后自动执行逻辑，无需点击“重新开启并检查”。

已在用户的极米 Z7X 高亮版上，通过 ADB 注入遥控器同等 Android 方向键及 OK 键事件进行验证，并检查实机截图和 UI 状态：四方向切换、白框放大、OK 切换、设置重启应用后保留、OK 重新检查后诊断文件更新时间均通过。开机恢复选项已恢复为测试前的开启状态。

本版没有更改底层 ADB 开启命令；整机重启后的恢复不在本次验证范围内。

下载 Z7X-ADB-v1.1.0.apk 可覆盖安装 v1.0.0，签名保持一致。
